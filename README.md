# ReAlgo — финальная презентация

Автономный HTML-дек на 19 слайдов для 10-минутного онлайн-выступления.
Сценарий занимает около 8:50 и оставляет запас на переключения и финальную паузу.

## Запуск

Самый надёжный вариант:

```bash
cd /Users/madtrip/realgo-final-deck
python3 -m http.server 4173
```

После этого открыть `http://127.0.0.1:4173` в актуальном Chrome и включить полный экран.
Chrome нужен для переходов Magic Move на базе View Transitions API.
Для трёхмерного MacBook также должен быть включён WebGL.

Можно открыть `index.html` напрямую, но локальный сервер надёжнее воспроизводит видео.

## Docker

Запуск через Docker Compose:

```bash
docker compose up --build
```

После сборки презентация доступна на `http://localhost:8080`.

Запуск без Compose:

```bash
docker build -t realgo-final-presentation .
docker run --rm -p 8080:80 realgo-final-presentation
```

Для остановки Compose-контейнера:

```bash
docker compose down
```

## Управление

- `←` / `→` — предыдущий или следующий слайд
- `Space` — следующий слайд
- `N` — показать или скрыть заметки спикера
- `F` — полноэкранный режим
- `R` — сбросить таймер выступления
- `?` — подсказка по управлению

Номер слайда можно открыть через hash: `http://127.0.0.1:4173/#7`.

## Состав

- `index.html` — содержание презентации
- `apple.css` — минималистичная Keynote-визуальная система и анимации
- `deck.js` — навигация, таймер и заметки спикера
- `macbook-3d.js` — Three.js-сцена, непрерывная камера, кинематографичный свет и видеотекстуры экрана
- `assets/product-extension.mp4` — демонстрация реального компонента расширения: оценка, сохранение и карточки
- `assets/product-agent.mp4` — демонстрация реального AI-компонента с потоковой подсказкой
- `assets/agent.png` — резервный кадр AI-агента до загрузки видео
- `assets/models/macbook-pro-m3-16.glb` — локальная модель MacBook Pro
- `vendor/three/` — локальная сборка Three.js без CDN
- `archive/v1/` — предыдущая 12-слайдовая версия
- `qa/apple/` — контрольные кадры новой версии в разрешении 1920×1080
- `qa/product-capture/` — воспроизводимый стенд записи на компонентах из актуального репозитория ReAlgo

Расширение и AI-агент проигрываются как H.264-видео на экране живой 3D-модели MacBook. Запись собрана из тех же `PopupApp` и `AssistantApp`, которые использует расширение, поверх детерминированной сцены задачи. Слайды с рыночными данными содержат кликабельные источники мелким шрифтом.

MacBook занимает весь экран без рамки слайда. Камера плавно приближается к нужной зоне интерфейса и продолжает движение между демонстрацией расширения и AI-агента; движение за курсором отключено. Устройство проявляется из темноты под узким верхним и холодным контурным светом, а точная геометрия гравировки клавиатуры светится белым.

Переходы связывают объекты между соседними слайдами: числа преобразуются в следующие метрики, схема цикла превращается в полноэкранный ноутбук, продуктовый экран перестраивается в AI-интерфейс, карточки переходят в Pattern Atlas, а цены — одна в другую.

На слайдах 2–4 крупная метрика закреплена в одной точке и сохраняет одинаковый кегль. При смене слайда значение за 1,28 секунды численно проходит промежуточные значения: дробная часть с запятой растворяется перед целым числом, а знак процента проявляется через мягкую маску. Верхняя подпись, тезис, пояснение и источники сменяются отдельными переходами.

Модель MacBook создана Maroi Mister Let Me Think Official 3D Studio и распространяется по CC BY 4.0. Атрибуция и ссылка на исходную страницу Sketchfab указаны непосредственно на продуктовых слайдах.
